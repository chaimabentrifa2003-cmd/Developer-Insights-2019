# Developer Insights 2019

Interactive dashboard for Stack Overflow Developer Survey 2019.

## Project Description

Developer Insights 2019 is a Business Intelligence project
based on the Stack Overflow Developer Survey 2019.

The objective is to explore developer profiles, programming
languages, professional experience, salaries and technologies.

## Technologies

- Python
- Pandas
- NumPy
- Streamlit
- Plotly

## Installation

1. Clone the repository.
2. Create a virtual environment:

```bash
python -m venv venv
```

3. Activate the environment on Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

4. Install dependencies:

```bash
pip install -r requirements.txt
```

## Dataset Setup

1. Download the Stack Overflow Developer Survey 2019 dataset
   (official Stack Overflow survey page or Kaggle).
2. Place `survey_results_public.csv` inside the `data/` directory.

The full file is too large for GitHub and is excluded with `.gitignore`.

If the full file is missing, the application falls back to
`data/survey_sample.csv`, a reproducible sample of 5000 rows
(`random_state=42`) generated by `src/make_sample.py`.

The schema file `data/survey_results_schema.csv` is included in the repository.

## Data Loading

The module `src/data_loader.py` provides the
`load_data()` function to load the survey dataset
using Pandas.
