# Contributing

## Branches
- One task per branch: `feature/...`, `fix/...`, `docs/...`, `chore/...`
- Branch from an up-to-date `main`.

## Commits
- Written in English, in the imperative mood.
- Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `chore:`
- One logical change per commit.
- Fix a mistake with `git commit --amend` before pushing.

## Pull requests
- The other member reviews and approves before merge.
- Keep a linear history: `git pull --rebase` before pushing.
